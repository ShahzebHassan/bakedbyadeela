# Baked By Adeela

A responsive floral cake studio website for Birmingham and the Midlands.

## Confirmed requirements
- Real photographs supplied by the client, with the original cake details preserved.
- Pastel blush, lilac, sage and ivory. Olive & Mac is the user-pinned structural reference: wide single coloured header, elegant text wordmark, large photographic opening.
- Website brand is typographic Baked By Adeela; the circular logo is reserved for social media.
- Home, about, customer journey, flavours, cupcake bouquets, celebration cakes, weddings, contact and journal.
- One enquiry form on enquiry.html, reached from buttons and product links. It is not embedded in other pages. Product links prefill category and design.
- Netlify Forms submissions (explicitly chosen by user).
- Local search content for Birmingham / Midlands; sitemap, canonical metadata and structured data.
- Instagram gallery requested. No widget or credentials supplied. The Netlify function is ready for authorised account access; until then, supplied portfolio photographs link to Instagram.

## Unconfirmed
Final recipes/flavour menu, prices, exact collection address, delivery policy and fuller biography. Do not invent awards, reviews, precise availability, or service guarantees.

## Deployment
Public repository ShahzebHassan/bakedbyadeela. Production URL https://bakedbyadeela.netlify.app/.
Python generates HTML into dist. CSS and JavaScript live in dist. Netlify build runs python build.py and publishes dist. Server function reads Instagram credentials only from the deployment environment.

## 24 November collection update
Client requested three Wedding sections (Dome bouquets, Wedding cakes, Large wedding bouquets) and three Cupcake bouquet sections (Standard, Premium, Luxury). Client authorised assigning designs by our judgement. Assignments are based on visible floral complexity, with no fixed price or portion claims. Client also requested brightness/background adjustments for nine supplied photographs; edited versions are kept separate from archived originals.
